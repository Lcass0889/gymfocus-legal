# gymfocus-legal

Documentos legais do app **GymFocus**, publicados via GitHub Pages porque a App
Store exige uma URL pública de política de privacidade (diretriz 5.1.3, por
causa do HealthKit) e termos de uso acessíveis (diretriz 1.2, conteúdo gerado
por usuário).

- Política de Privacidade: <https://lcass0889.github.io/gymfocus-legal/politica-de-privacidade/>
- Termos de Uso: <https://lcass0889.github.io/gymfocus-legal/termos-de-uso/>

**As fontes destes textos vivem no repositório do app**, em
`docs/politica-de-privacidade.md` e `docs/termos-de-uso.md`. Ao alterar lá,
copie para cá — os dois precisam continuar iguais, senão o app promete uma coisa
e o documento publicado diz outra.

As URLs acima estão gravadas em `src/lib/legal.ts` no app (ponto único). Mudar o
endereço aqui obriga a atualizar aquele arquivo.
